================================================================================
 СИМУРГФАРМ · ВЕБ-ПРИЛОЖЕНИЕ ДЛЯ ВРАЧА-КЛИНИЦИСТА
 СППР (Система поддержки принятия врачебных решений) по дозированию Экзампломицина
================================================================================

ОПИСАНИЕ СИСТЕМЫ:
Интерактивное клиническое веб-приложение для персонализированного расчета 
дозы и прогнозирования фармакокинетического профиля инновационного антибиотика
«Экзампломицин» на основе золотого набора из 6 ключевых биомаркеров пациента.

КАК ЗАПУСТИТЬ:
В приложении реализовано два варианта запуска:

ВАРИАНТ 1 (Самый простой — без Python и без интернета):
  Просто дважды кликните по файлу:
  👉 index.html
  или запустите:
  👉 start_app.bat
  Приложение откроется в любом современном браузере (Chrome, Edge, Yandex, Firefox)
  и будет работать со скоростью 60 FPS локально.

ВАРИАНТ 2 (Через локальный Python веб-сервер):
  Запустите:
  👉 python run_server.py
  Приложение автоматически откроется по адресу http://localhost:8080/index.html.

ФУНКЦИОНАЛ СИСТЕМЫ:
1. «Золотой стандарт» 6 параметров:
   - Масса тела (кг)
   - Возраст (лет)
   - Креатинин сыворотки крови (мкмоль/л)
   - Наличие сепсиса / синдрома системного воспалительного ответа (СВР)
   - Альбумин плазмы крови (г/л)
   - Вариант гена транспортера SLC22A6/SLC22A8 (OAT1/OAT3): Normal, Slow, Rapid.

2. Мгновенный расчет и подбор безопасной дозы:
   - Расчет разовой дозы в миллиграммах (мг) и граммах (г).
   - Точные инструкции по инфузии (100 мл 0.9% NaCl за 30 мин).

3. «Светофор безопасности» и контроль токсичности:
   - Зеленый щит безопасности: C_peak(0.5 ч) <= 26.0 мг/л.
   - Оценка терапевтического диапазона: C_avg(0-12 ч) в диапазоне 6.0–26.0 мг/л.
   - Прогнозируемая вероятность бактериологического излечения PTA >= 90%.
   - Автоматическое предупреждение и блокировка при превышении токсического порога.

4. 60 FPS Canvas PK-кривая:
   - Интерактивный график падения концентрации антибиотика за 24 часа.
   - Наведение курсора с плавающим тултипом и контролем терапевтического коридора.

5. Официальный медицинский протокол (A4):
   - Кнопка «Распечатать назначение в историю болезни (A4)».
   - Готовая форма для вклейки в карту стационарного больного с полями для подписей
     лечащего врача и заведующего отделением реанимации.

6. Пресеты клинических случаев:
   - Пациент из Слайда 12 презентации (Мужчина 65 лет, 78 кг, сепсис).
   - Пациент с тяжелым септическим шоком и гипоальбуминемией.
   - Молодой пациент с гиперклиренсом OAT Rapid.
   - Пожилая пациентка с хронической болезнью почек (ХБП).
